# BOM 模板数据结构

模板定义位于 `data/templates.json`，示例工作表位于 `data/mock.json`。
两个文件都必须保持合法 JSON，因此不能在文件内写 `//` 注释。
本文件用于说明模板库和字段结构的含义。

## 模板库

```json
{
  "version": "1.0",
  "defaultTemplateId": "tpl_bom_standard_v1",
  "templates": []
}
```

- `defaultTemplateId`：推荐的内置模板标识。
- 页面当前不会自动选中该模板，用户仍从“请选择模板”开始操作。
- `templates`：内置模板列表，后续可替换为服务端模板接口。

## 模板选择

- 下拉框按 `builtIn` 属性分为“内置模板”和“我的模板”。
- 当前没有自定义模板时，“我的模板”显示空状态。
- 页面不会自动选择模板，用户必须主动选择。
- “清除当前模板”只清除任务窗格中的当前选择，不删除模板定义。

## 模板配置预览

- 模板配置按分组折叠展示，第一个分组默认展开。
- 分组摘要显示当前可见字段数量。
- 每个字段显示“显示/隐藏”状态和完整字段路径。
- 复选框可以临时切换字段显隐，隐藏字段会从字段列表和上传结果中排除。
- 隐藏字段仍保留原始源列位置，避免后续字段错列。
- 至少需要保留一个可见字段。
- 当前显隐调整仅在本次会话生效，刷新后恢复模板默认配置。

## 自定义字段

- 每个分组可以添加“自定义字段”。
- 新增字段使用独立 `customN` key，并默认标记为 `builtIn=false`。
- 自定义字段可以重命名和删除，内置字段不能删除。
- 自定义字段尚未对应客户源表的列，因此存在自定义字段时会暂时禁用上传。
- 自定义字段目前只在本次会话生效，P12 保存为“我的模板”后再持久化。

## 我的模板

- 当前模板可以输入名称并保存为“我的模板”。
- 保存内容包含模板名称、分组、字段、显隐状态、自定义字段和字段顺序。
- 模板 ID 使用 `tpl_custom_时间戳_随机后缀`，避免与内置模板冲突。
- 自定义模板保存在当前浏览器的 `localStorage` 中，不会修改 `data/templates.json`。
- 刷新页面后仍可在下拉框的“我的模板”分组中找到。
- 页面仍然默认显示“请选择模板”，不会自动恢复上次选择。

## 应用模板到工作表

- 只使用当前可见字段生成两行表头。
- 第 1 行是合并后的分组表头，第 2 行是字段表头。
- 字段列宽根据字段名称自动计算。
- 浏览器 Mock 会清空当前示例数据，刷新页面可恢复原始 Mock。
- 真实 WPS 只允许写入空白工作表，已有内容时拒绝操作，防止覆盖客户数据。
- WPS 写入完成后会记录当前 Sheet 的模板布局标记，后续表头读取从第 2 行开始。

## 两行表头识别

- 单行表头模式：第 1 行是字段名，第 2 行开始是数据。
- 两行表头模式：第 1 行是合并分组，第 2 行是字段名，第 3 行开始是数据。
- 合并单元格右侧的空白列会沿用左侧最近的分组名称。
- 完整表头使用“分组 / 字段”形式，例如“产品定义 / 产品编号”。
- 任务窗格会显示当前是单行表头还是两行分组表头。

## 模板

```json
{
  "id": "tpl_bom_standard_v1",
  "name": "BOM 标准模板（示例）",
  "builtIn": true,
  "version": 1,
  "groups": []
}
```

- `id`：模板唯一标识。
- `name`：页面显示名称。
- `builtIn`：是否为系统内置模板。
- `version`：模板结构版本，用于后续判断模板是否需要升级。
- `groups`：表头分组，顺序决定字段在工作表中的默认列顺序。

## 分组

```json
{
  "key": "product",
  "label": "产品定义",
  "visible": true,
  "builtIn": true,
  "fields": []
}
```

- `key`：分组唯一标识，同时作为字段路径的第一段。
- `label`：页面显示名称，例如“产品定义”。
- `visible=false`：整组隐藏，展开模板时不会生成字段。
- `builtIn`：是否为内置分组。
- `fields`：分组内的字段列表。

## 字段

```json
{
  "key": "productCode",
  "label": "产品编号",
  "visible": true,
  "builtIn": true,
  "aliases": ["物料编码", "料号"]
}
```

- `key`：字段唯一标识，与分组 key 组合成完整字段路径。
- `label`：当前模板表头显示名称。
- `visible=false`：字段不进入字段列表，也不参与上传。
- `builtIn=false`：预留给后续自定义字段。
- `aliases`：自动识别客户表头时使用的候选名称，当前步骤只保存，尚未参与匹配。

## 当前默认分组

- `product`：产品定义，7 个字段。
- `bom`：物料清单，6 个字段。
- `route`：工艺路线，2 个字段。

当前 BOM 模板不包含时间相关字段。
